# Hi, I'm Surendra Matta

I work across technical support, marketing technology, e-commerce and analytics. I enjoy turning operational problems into practical software that people can understand and use.

My background includes advertiser support, Shopify development, campaign tracking and data analysis. My projects explore how those skills can make job-search workflows more transparent and easier to manage.

## How I approach a project

Understand the user's goal, reproduce the problem, make a focused change, and verify the result. I value honest status reporting: a generated draft is not a submitted application, and a passing build is not a finished product.
